# Evaluation / Benchmark Harness

v13 adds systematic evaluation for the Harness itself.

## Goals

Measure whether changes to:
- prompts
- agent roles
- graph strategy
- governance policy
- memory usage
- model choice
- DAG policy

actually improve delivery quality.

## Evaluation Types

- benchmark tasks
- golden expectations
- regression suite
- A/B experiments
- model comparison
- policy comparison
- prompt comparison
- failure-rate tracking

## Key Metrics

- task success rate
- verification pass rate
- retry count
- replan count
- lead time
- node count
- unexpected impact count
- review findings
- PR gate failures
- self-correction success rate
