# Dynamic DAG Examples

## API-only bug fix
Planner → Impact → Backend → Test → Review → PR

## UI-only change
Planner → Impact → Frontend → Playwright → Review → PR

## Full-stack feature
Planner → Impact → Backend / Frontend / Migration → Integration
→ Test / Playwright → Review → PR

## Security-sensitive auth change
Planner → Impact → Backend / Frontend → Integration
→ Test / Security Review → Review → PR

## Documentation-only
Planner → Docs → Review → PR
