# SCIP Integration

SCIP is a language-agnostic semantic code intelligence format.

Use it when you need high-confidence semantic information such as:
- definitions
- references
- implementations
- symbol identity
- compiler/indexer-derived relationships

## Expected Artifact

Place generated indexes under:

`graph/scip/`

Example:

`graph/scip/index.scip`

The actual indexer depends on language/toolchain.

## Harness Role

SCIP is a specialist semantic source.
It complements GitNexus rather than replacing the agent-oriented process/impact graph.
