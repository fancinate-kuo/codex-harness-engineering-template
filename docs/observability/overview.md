# Harness Observability

v10 adds execution observability for agentic software delivery.

## Goals

Measure whether the Harness is:
- faster
- more reliable
- less wasteful
- easier to debug
- improving over time

## Observed Entities

- task
- DAG
- node
- agent
- retry
- replan
- graph query
- test run
- review
- PR gate
- approval
- failure classification

## Outputs

- append-only audit log
- task metrics
- node metrics
- decision trail
- summary report
